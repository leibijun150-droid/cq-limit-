
# 重庆桥隧限行智能出行顾问

**作者**：陈文强
**日期**：2026-10-12
**许可**：保留所有权利

## 这是什么

一个手机端网页小工具。输入车牌、车型、星期、时间、
途经桥隧，自动判断工作日高峰时段是否受桥隧错峰通行限制，
并给出判断依据和出行建议。

## 规则依据

《重庆中心城区高峰时段桥隧错峰通行通告》
施行期：2026年3月1日 — 2027年2月28日

## 使用方法

浏览器打开 index.html，填好表单，点「判断限行」。
